# Shared — Reusable Presentational Components

This directory contains reusable presentational components shared across sections.

## Usage Rules

- Components should be framework-agnostic (prefer `.astro` files).
- No business logic or complex state.
- Focus on typography, layout, and common UI patterns.
- Mobile-first responsive design.

## Examples

- Container
- Section wrapper
- Heading
- Paragraph
- Link
- Button (base styles)

## File Naming

Use kebab-case: `container.astro`, `section-wrapper.astro`
