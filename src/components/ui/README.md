# UI — shadcn/ui Components

This directory will contain shadcn/ui components customized for the LabXR dark cinematic theme.

## Usage Rules

- Do not manually create components here yet.
- Components will be added via shadcn/ui CLI in Phase 2.
- Customize via `tailwind.config.js` and CSS variables.
- Never hardcode colors — use theme variables.

## Future Components

- Button
- Input
- Dialog
- Form
- Card
- Dropdown

## File Naming

Follow shadcn/ui conventions: `button.tsx`, `input.tsx`
