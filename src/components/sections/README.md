# Sections — Astro Page Sections

This directory contains Astro components for page sections.

## Usage Rules

- Use `.astro` files for static structure.
- No client-side JavaScript unless absolutely necessary.
- Sections should be self-contained and reusable.
- Follow mobile-first responsive design.

## Examples

- Hero section
- Manifesto section
- Services section
- Portfolio section
- Team section
- Contact section

## File Naming

Use kebab-case: `hero-section.astro`, `portfolio-section.astro`
