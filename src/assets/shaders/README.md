# Shaders — GLSL Shader Files

This directory will contain GLSL vertex and fragment shader files for Three.js and WebGL experiences.

## Usage Rules

- Use `.glsl`, `.vert`, or `.frag` extensions.
- Document shader purpose and parameters.
- Optimize for mobile performance.
- Test with reduced motion preferences.

## Future Content

- Particle system shaders
- Distortion effects
- Color grading LUTs
- Post-processing effects

## File Naming

Use descriptive kebab-case: `particle-vertex.glsl`, `distortion-fragment.glsl`
