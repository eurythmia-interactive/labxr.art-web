# Config — Configuration Files

This directory contains typed environment configuration and site configuration.

## Usage Rules

- Export typed configuration objects.
- Use Astro environment variables correctly.
- Only expose `PUBLIC_` prefixed variables to the browser.
- Never commit secrets or API keys.

## Examples

- Site metadata configuration
- Environment variable validation
- Feature flags
- API endpoints configuration

## File Naming

Use camelCase: `site.ts`, `env.ts`
