# Lib — Utilities and Helpers

This directory contains non-UI logic, utilities, helpers, and constants.

## Usage Rules

- Pure TypeScript/JavaScript functions.
- No React or Astro components.
- Keep functions small and single-purpose.
- Export typed interfaces for reusability.

## Examples

- Device detection utilities
- Date formatting helpers
- Constants and configuration values
- Type definitions
- Validation functions

## File Naming

Use camelCase for utilities: `deviceDetection.ts`, `dateHelpers.ts`
